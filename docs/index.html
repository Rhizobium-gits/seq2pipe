3層アーキテクチャ。
判断と実行を分離。

判断は確定的・LLM 不要。コード生成だけが LLM を使う。

L1

DataInspector

TSV を直接パース → Mann-Whitney U / Kruskal-Wallis / PERMANOVA
純 Python。scipy 不要。実行時にデータから統計的特徴を計算。
L2

BayesianReasoner + DecisionEngine

7 仮説をベイズ更新 → 確信度に基づいて skip/add を判断
確定的。再現性 100%。重みに非依存（10,221 設定で証明）。
L3

LLM (qwen2.5-coder:7B)

コード生成 (47%) + 仮説提案 (25%)
判断には不使用。ローカル実行。API キー不要。

3行で始める。

# インストール
git clone https://github.com/Rhizobium-gits/seq2pipe.git
cd seq2pipe && ./setup.sh

# Lite モードで解析（推奨）
./launch.sh --fastq-dir ~/data --lite \
  --metadata meta.tsv --research-question "Your question"

# Docker
docker build -t seq2pipe:3.0 .
docker run -v ~/data:/data seq2pipe:3.0 --lite --fastq-dir /data
