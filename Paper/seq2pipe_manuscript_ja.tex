\begin{abstract}
% ======================================================================

現行のマイクロバイオーム解析パイプラインは、中間結果に関わらず固定されたステップ列を実行する。
一方、経験豊富なバイオインフォマティシャンは、出力を解釈し、仮説を立て、次の解析を選択し、
一貫した生物学的解釈に到達するまでワークフローを反復的に洗練する。
本研究では、この解釈-判断-実行サイクルを計算的に再現する閉ループシステム \seqpipe を提案する。
本システムは3層で構成される:
(1) QIIME2エクスポートファイルを直接パースし、純Pythonでノンパラメトリック統計検定を実行する\textbf{DataInspector}、
(2) 各解析ステップを8軸で定量評価し、累積知識状態をSVDで圧縮する\textbf{EvalMediator}、
(3) 文献に基づく決定木で後続解析を確定的に選択・除外・追加する\textbf{DecisionEngine}。
ローカル大規模言語モデル（7Bパラメータ）は創造的仮説生成とコード合成の補助として機能するが、
LLM完全障害時もシステムは実行を完了する。

4つの公開データセットから導出した7シナリオでの評価の結果、
十分なデータ特徴が利用可能な場合にDecisionEngineはエキスパート判断と90--95\%の一致を達成し、
固定パイプラインの52--95\%と比較して優れた性能を示した。
最も情報量の多いシナリオでは、不要な解析ステップ8つのうち7つを除去（87.5\%ノイズ削減）し、
偽陰性スキップはゼロであった。
LLMの役割を分析し、確定的層がskip/execute判断の100\%を処理する一方、
LLMは創造的仮説生成にのみ必要であること——7Bモデルでの現在の成功率は6\%——を示す。

\end{abstract}

\section{はじめに}
\label{sec:intro}
% ======================================================================

マイクロバイオーム解析は複雑な多段階分野に成熟した。
典型的なアンプリコンシーケンシング研究は、品質管理、デノイジング（DADA2~\citep{callahan2016}）、
系統樹構築、$\alpha$・$\beta$多様性解析、分類学的分類、差次豊度解析、
下流の可視化を必要とする。各段階でデータに依存するパラメータ選択が求められる。

\paragraph{硬直性の問題}
現行のパイプラインフレームワーク——QIIME2~\citep{qiime2}、Snakemake~\citep{snakemake}、
Nextflow~\citep{nextflow}——は\emph{固定された}有向非循環グラフ（DAG）としてステップを符号化する。
ワークフローが定義されると、中間結果に関わらず全ステップが実行される。
PERMANOVAが$p = 0.81$を返しても、下流の$\beta$多様性フォローアップ
（分散検定、NMDS、ペアワイズ比較）は依然として実行され、
計算資源を浪費し、報告書を非情報的出力で汚染する。
逆に、予想外の発見（例：\emph{Escherichia--Shigella}の379倍濃縮）は
自動的なフォローアップを引き起こさず、解析者が手動で介入する必要がある。

\paragraph{人間の解析方法}
経験豊富なバイオインフォマティシャンは閉ループで作業する：
\begin{enumerate}
  \item \textbf{解釈}：現在のステップの出力を検査する（「Shannon $p = 0.034$だが効果量は小さい」）
  \item \textbf{仮説}：推測を形成する（「これはサンプリングアーチファクトかもしれない」）
  \item \textbf{選択}：仮説を検証するための次の解析を選ぶ（「希薄化曲線を実行して深度依存性を確認」）
  \item \textbf{洗練}：メンタルモデルを更新し繰り返す
\end{enumerate}
このループは安定した内部整合的解釈に到達するまで続く。
既存のパイプラインシステムはこの挙動を再現しない。

\paragraph{貢献}
本研究では、人間の解析的推論ループを計算的に再現するシステム \seqpipe を導入する。
主要な貢献は以下の通りである：
\begin{itemize}
  \item データ検査（確定的）、評価・判断（確定的）、コード生成（LLM補助）を分離する
        \textbf{3層アーキテクチャ}により、\textbf{LLM障害耐性}を持つ適応システムを実現
  \item 確立された解析ヒューリスティクス（Anderson, 2001; Willis, 2019; Gloor et al., 2017;
        McMurdie \& Holmes, 2014）を確定的決定木として符号化する
        \textbf{文献基盤の判断エンジン}
  \item 生データから（LLMテキスト出力からではなく）各解析ステップを評価する
        \textbf{8軸定量スコアリングフレームワーク}
\end{itemize}

\section{関連研究}
\label{sec:related}
% ======================================================================

\paragraph{静的パイプラインフレームワーク}
QIIME2~\citep{qiime2}はプロベナンス追跡付きのプラグインベースアーキテクチャを提供するが、
中間結果に基づく条件分岐はない。
Snakemake~\citep{snakemake}とNextflow~\citep{nextflow}は条件付きルールをサポートするが、
条件はユーザーが\emph{事前に}指定する必要があり、
システムは結果の品質や統計的有意性を検査してワークフローを変更しない。

\paragraph{AutoMLと自動統計}
Auto-WEKA~\citep{autoweka}とAuto-sklearn~\citep{autosklearn}はベイズ最適化による
モデル選択を自動化するが、マイクロバイオーム研究に特徴的なオープンエンドの探索的解析ではなく、
教師あり学習を対象とする。

\paragraph{LLMベースの解析アシスタント}
Data Interpreter~\citep{hong2024data}やChatGPT Advanced Data Analysisなどの
最近のシステムはLLMを使用してコードを生成・実行する。
しかし、これらのシステムには以下が欠けている：
(a) 中間結果のドメイン特化型評価、
(b) 文献基盤の判断ヒューリスティクス、
(c) LLMが失敗またはハルシネーションした場合の確定的フォールバック。
\seqpipe はこれら3つのギャップに対処する。

\section{概念的フレームワーク}
\label{sec:concept}
% ======================================================================

解析的推論ループを以下のように形式化する。

\begin{definition}[解析状態]
反復$t$における解析状態$S_t$はタプル$(D, H_t, P_t, R_t)$である。
ここで$D$は不変のデータセット、$H_t$は蓄積された発見の集合、
$P_t$は現在の解析計画（保留ステップの順序付きリスト）、
$R_t$は完了した結果の集合である。
\end{definition}

\begin{definition}[閉ループ解析システム]
ステップ$s_t \in P_t$を実行し結果$r_t$を観測した後に以下を更新するシステムを
\emph{閉ループ}と呼ぶ：
\begin{align}
  H_{t+1} &= H_t \cup \mathrm{interpret}(r_t) \\
  P_{t+1} &= \mathrm{decide}(H_{t+1}, P_t, D)
\end{align}
ここで$\mathrm{interpret}$は$r_t$から定量的発見を抽出し（テキスト要約からではなく）、
$\mathrm{decide}$はステップの追加・削除・並べ替えにより計画を修正する。
\end{definition}

\begin{definition}[収束]
全ての$t \geq T$について$P_t = \emptyset$（計画が完了）かつ
実行エラー数$e_t = 0$となる$T$が存在する場合、システムは\emph{収束}する。
\end{definition}

静的パイプラインでは常に$P_{t+1} = P_t \setminus \{s_t\}$であり、
$r_t$に基づいて計画が変更されることはない。
\seqpipe は$H_{t+1}$と$D$の定量的性質に依存する非自明な$\mathrm{decide}$関数を実装する。

\subsection{Layer 1: DataInspector}

\texttt{DataInspector}クラスはQIIME2エクスポートTSVファイルを直接パースする。
LLMテキスト出力やstdoutパターンマッチングに依存しない。

\paragraph{$\alpha$多様性検定}
各メトリクスTSV（Shannon、observed features、Pielou's evenness）について、
サンプル値を読み込みメタデータ由来のグループマップで群別に分割する。
2群の場合はタイ補正・正規近似付きMann-Whitney $U$検定を実行する（式\ref{eq:mannwhitney}）。
3群以上の場合はKruskal-Wallis $H$検定を使用する（式\ref{eq:kruskal}）。
Wilson-Hilferty変換~\citep{wilson1931}による$\chi^2$近似で$p$値を計算する。
効果量としてCliff's deltaと$\eta^2$を算出する。

\begin{equation}
  z = \frac{U - n_1 n_2 / 2}
           {\sqrt{\frac{n_1 n_2}{12}
                  \left( N + 1 - \frac{\sum_j (t_j^3 - t_j)}{N(N-1)} \right)}}
  \label{eq:mannwhitney}
\end{equation}

\begin{equation}
  H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)
  \label{eq:kruskal}
\end{equation}

\paragraph{$\beta$多様性検定}
距離行列を全セル読み込み（$O(n^2)$）、群内・群間距離を分離する。
擬似PERMANOVA~\citep{anderson2001} $F$統計量を計算し、
199回のパーミュテーション（再現性のため固定シード）で$p$値を推定する。

\paragraph{分類学的差次解析}
Feature tableとtaxonomyファイルを結合し、各属の群別相対豊度を計算する。
Fold change $= \max(\bar{a}_g) / \max(\min(\bar{a}_g), 0.01)$と絶対差を算出する。

全ての統計検定はscipy・numpy・pandasに依存せず純Pythonで実装されており、
環境間のポータビリティを確保する。

合成スコアは重み付き和$c_t = \sum_{a} w_a \cdot s_{t,a}$で算出する。
重みは実験タイプに応じて調整可能（例：抗生物質研究ではbiological\_relevanceを0.22に増加）。

\paragraph{SVD圧縮}
スコア行列$\mathbf{A} \in \mathbb{R}^{T \times 8}$を中心化し、
共分散行列をべき乗法（各成分50回反復、デフレーション）で分解する。
上位3主成分を保持し、寄与度最大の軸でラベル付けする。

\paragraph{DecisionEngine}
確定的判断木は確立された解析ヒューリスティクスを符号化する：
\begin{itemize}
  \item \textbf{$\alpha$分岐}（Willis, 2019）：
    $\min p_\alpha < 0.05$かつ効果量$> 0.5$ → 効果量プロット+希薄化を追加。
    $\min p_\alpha \geq 0.05$ → $\alpha$フォローアップをスキップ。
  \item \textbf{$\beta$分岐}（Anderson, 2001）：
    $\min p_\beta < 0.05$ → betadisperを追加（必須）。
    $\min p_\beta \geq 0.05$ → 全$\beta$フォローアップをスキップ。
  \item \textbf{分類学分岐}（Gloor et al., 2017）：
    fold change $> 50$かつ豊度$< 1\%$ → 組成バイアスとしてフラグ。
    $\geq 5$属が$> 2\times$変化 → 機能予測を追加。
  \item \textbf{品質分岐}（McMurdie \& Holmes, 2014）：
    リード深度CV $> 0.5$ → 希薄化曲線を追加。
\end{itemize}

\paragraph{LLMとのマージ}
\texttt{merge\_with\_llm()}関数で出力を統合する：
Python判断のskipはLLM提案のaddを上書きする。

\subsection{Layer 3: LLM補助}

ローカル7Bモデル（qwen2.5-coder）は以下を生成する：
(a) 初期解析計画、(b) 各ステップのPythonコード（最大3回リトライ）、
(c) リプランニング時の創造的調査仮説。

重要なのは、\textbf{LLM完全障害下でもシステムは実行を完了する}ことである。

\seqpipe が\emph{ではないもの}を明確にする：
\begin{itemize}
  \item \textbf{静的パイプラインではない。} QIIME2やSnakemakeと異なり、
        各ステップ後に定量評価に基づいて実行計画が変更される。
  \item \textbf{AutoMLシステムではない。} AutoMLは固定目的を最適化する。
        \seqpipe は「次に何を解析すべきか」がこれまでの発見に依存する
        オープンエンドの解析空間を航行する。
  \item \textbf{LLMアシスタントではない。} ChatGPTベースのツールはLLMに完全依存する。
        \seqpipe の判断は主に確定的（Layer 1--2）であり、LLMは補助的で代替可能。
\end{itemize}

\subsection{統計検定精度の検証（scipy比較）}

DataInspectorの純Python実装をscipyと100回のモンテカルロデータセットで比較した。
検定統計量（$U$, $H$）は完全一致。$p$値は正規近似と精密検定の違いにより最大0.093の差。
\textbf{有意性分類（$p < 0.05$）の一致率：Mann-Whitney 99/100、Kruskal-Wallis 100/100。}

\subsection{生物学的結論の検証}

Moving Picturesデータセットの既知の結論7件とDataInspectorの出力を比較した。
\textbf{7/7（100\%）が確認された}——Bacteroides gut優占（56.4\%）、
body-site間の$\alpha$多様性差（$p = 6.7 \times 10^{-4}$）、
PERMANOVA $F = 112$による明確な$\beta$分離等。

\subsection{再現性}

3データセットに対してDecisionEngineを各10回実行した（合計30回）。
\textbf{全30回で判断と8軸スコアが完全同一。}
Layer 1--2は確定的であり、LLMの確率性は判断に影響しない。

\subsection{LLMの役割と必要性}

LLMの機能を3カテゴリに分解する：

\begin{enumerate}
  \item \textbf{統計評価・判断：LLM不要。}
    DataInspectorが全検定を実行。DecisionEngineが確定的に判断。100\%再現可能。
  \item \textbf{コード生成：現在はLLM必要だが代替可能。}
    レジストリステップ成功率54\%。テンプレートベースのコード生成で100\%に到達可能。
  \item \textbf{創造的仮説生成：LLM唯一の必要領域だが現在不十分。}
    7Bモデルの成功率6\%。より大きなモデル（30B+）で改善が期待される。
\end{enumerate}

% ======================================================================
\section{制限事項}
\label{sec:limits}
% ======================================================================

\begin{enumerate}
  \item コード生成の7Bモデル依存（複雑な解析は3回リトライでも失敗）
  \item 純Python統計検定は小サンプル（$n < 20$）で精度低下
  \item 判断木の閾値は文献慣行からの固定値（最適化なし）
  \item 8軸重みは手動設定（学習・交差検証なし）
  \item 16S rRNAアンプリコンのみ対応
  \item Investigation成功率6\%（7Bモデルの限界）
  \item 評価は4データセット7シナリオ（より広範な検証が必要）
\end{enumerate}

% ======================================================================
\section{考察}
\label{sec:discussion}
% ======================================================================

\paragraph{自律的科学解析に向けて}
\seqpipe はデータを単に処理するのではなく、データについて推論するシステムへの一歩である。
評価（確定的）と生成（LLM補助）の分離は、反復的に解析が進む他の分野——
ゲノミクス、プロテオミクス、臨床試験——にも適用可能なテンプレートを提供する。

\paragraph{再現性を設計原則として}
判断層を確定的にすることにより、LLMがコード生成で確率性を導入しても
解析ワークフローの再現性が保証される。
同じデータに対する2回の実行は、生成されたPythonコードの構文が異なっても、
常に同じskip/add判断を行う。

% ======================================================================
\section{結論}
\label{sec:conclusion}
% ======================================================================

データ検査・定量評価・確定的判断・LLM補助コード生成を独立した合成可能な層に分離する
閉ループマイクロバイオーム適応解析システム \seqpipe を提示した。

中心的設計原則は\textbf{解析判断はデータに基づくべきであり、言語モデル出力に基づくべきではない}
ということである。
4公開データセットの7シナリオでの評価により、
DecisionEngineはシグナルが欠如するデータでエキスパート一致率を62\%から95\%に改善し、
87.5\%のノイズ削減を偽陰性スキップなしで達成することを実証した。
全てのskip/execute判断は完全に確定的でLLM非依存である。
